# QuantSeed

> 给软件工程学生的第一颗量化种子。
> 一个能跑、能读、能改、能继续长的 AI 量化研究框架。
> **已接上沪深 300 真实行情**（2023-01 ~ 2026-10，920 个交易日）。

---

## 这是什么

这不是一个玩具 demo。它是一个**完整的、分层的、可扩展的量化交易研究框架**，
你花一个下午跑通之后，会拥有：

- 一个**自己写的回测引擎**（不是调 backtrader，是你能逐行读懂的）
- 4 个经典策略的对照实验（双均线 / RSI 均值回归 / 唐奇安突破 / AI 投票组合）
- 一份自动生成的 HTML 回测报告（浏览器打开就能看）
- 一套**和 AI 协作做量化研究的 Prompt 模板**（这才是你关注的 AI coding）
- **真实 A 股数据接口**（akshare 新浪源，带本地缓存，第二次跑秒出）

## 怎么跑（30 秒）

```powershell
# 1. 装依赖
python -m pip install -r requirements.txt
# 想接真实数据，再装：
python -m pip install akshare

# 2. 一键跑（演示数据，0 外网依赖）
python run.py

# 3. 跑真实沪深300（2023年至今）
python run.py akshare 000300 2023-01-01

# 4. 换别的指数
python run.py akshare 399006 2023-01-01   # 创业板指
python run.py akshare 000905 2023-01-01   # 中证500

# 5. 用浏览器打开
results/report.html
```

## 泛化检验：哪些策略真的有 edge？

跑 `python run_research.py` 会做两件事：
1. **跨指数对比**：沪深300 vs 创业板指
2. **样本内外检验**：前 70% 数据当"过去"，后 30% 当"未来"

结果（节选）：

| 策略 | 沪深300 train | 沪深300 test | 创业板 train | 创业板 test | 判定 |
|---|---|---|---|---|---|
| RSI 均值回归 | +7.5% | **+4.0%** ✅ | -16.0% | -11.3% | 只在大盘有效 |
| 唐奇安突破 | +12.9% | -6.4% ❌ | +44.8% | -12.6% ❌ | **过拟合** |
| RSI+止损 | +13.0% | -6.3% ❌ | +37.6% | -18.1% ❌ | **过拟合** |
| 双均线 | -2.1% | -5.6% | -10.2% | +7.2% | 两边都不行 |

**这就是"断墨寻径"在量化里的样子：**
- 旧数据上赚 = **拟合**；新数据上也赚 = **学习**（泛化）
- 唐奇安在创业板 train 上赚 44%，test 上亏 12%——这就是教科书级的过拟合
- RSI 只在沪深300上有效，在创业板上崩——说明它的**前提条件是"低波动均值回归市场"**
- 加了止损后，样本内更好、样本外更差——这就是**奥卡姆剃刀**警告的：多一个参数就多一分过拟合

**没有圣杯策略。** 这就是真实的量化研究日常。
