# QuantSeed

> 给软件工程学生的第一颗量化种子。
> 一个能跑、能读、能改、能继续长的 AI 量化研究框架。
> **已接上沪深 300 真实行情**（2023-01 ~ 2026-10，920 个交易日）。

---

## 这是什么

这不是一个玩具 demo。它是一个**完整的、分层的、可扩展的量化交易研究框架**，
你花一个下午跑通之后，会拥有：

- 一个**自己写的回测引擎**（不是调 backtrader，是你能逐行读懂的）
- 4 个经典策略的对照实验（双均线 / RSI 均值回归 / 唐奇安突破 / AI 投票组合）
- 一份自动生成的 HTML 回测报告（浏览器打开就能看）
- 一套**和 AI 协作做量化研究的 Prompt 模板**（这才是你关注的 AI coding）
- **真实 A 股数据接口**（akshare 新浪源，带本地缓存，第二次跑秒出）

## 怎么跑（30 秒）

```powershell
# 1. 装依赖
python -m pip install -r requirements.txt
# 想接真实数据，再装：
python -m pip install akshare

# 2. 一键跑（演示数据，0 外网依赖）
python run.py

# 3. 跑真实沪深300（2023年至今）
python run.py akshare 000300 2023-01-01

# 4. 换别的指数
python run.py akshare 399006 2023-01-01   # 创业板指
python run.py akshare 000905 2023-01-01   # 中证500

# 5. 用浏览器打开
results/report.html
```

## 真实数据回测结果（沪深300，2023-01-03 ~ 2026-10-23）

这是用**真实 A 股指数**跑出来的数字，不是模拟数据：

| 策略 | 累计收益 | 年化 | 夏普 | 最大回撤 | 胜率 | 交易数 |
|---|---|---|---|---|---|---|
| 买入持有（基准） | +5.59% | — | — | — | — | — |
| **RSI 均值回归** | **+11.81%** | +3.11% | **0.11** | -21.43% | **66.7%** | 3 |
| 唐奇安突破 | +7.02% | +1.88% | -0.01 | -15.26% | 30.8% | 13 |
| AI 投票组合 | +2.65% | +0.72% | -0.13 | **-12.02%** | 38.5% | 13 |
| 双均线趋势 | -6.41% | -1.80% | -0.33 | -20.25% | 11.1% | 9 |

**这张表才是这个项目真正想教你的东西：**

1. **RSI 均值回归在真实沪深300上跑赢了基准一倍。** 不是演示数据上的巧合——
   2023-2024 年 A 股反复震荡探底，恐慌买入的策略确实吃到了肉。
2. **双均线在真实数据上还是亏。** 趋势策略在震荡市里被反复打脸，
   胜率只有 11%——但盈亏比 5.58，说明它靠极少数大赚撑着。这就是趋势跟踪的本质：
   平时小亏，一年等一两次大行情。
3. **组合策略回撤最小（-12%）但收益也最低。** 分散化的代价就是收益被摊薄，
   但它睡得着觉。你以后做实盘，回撤控制比收益重要。
4. **所有策略夏普都不到 1。** 这就是现实——单一个股指数上的简单技术策略，
   年化能跑赢基准 3-5 个点已经算不错。真正的 alpha 来自多因子、多标的、另类数据。
