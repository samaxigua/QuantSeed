# QuantSeed

> 给软件工程学生的第一颗量化种子。
> 一个能跑、能读、能改、能继续长的 AI 量化研究框架。
> **已接上沪深 300 真实行情**（2023-01 ~ 2026-10，920 个交易日）。

---

## 这是什么

这不是一个玩具 demo。它是一个**完整的、分层的、可扩展的量化交易研究框架**，
你花一个下午跑通之后，会拥有：

- 一个**自己写的回测引擎**（不是调 backtrader，是你能逐行读懂的）
- 4 个经典策略的对照实验（双均线 / RSI 均值回归 / 唐奇安突破 / AI 投票组合）
- 一份自动生成的 HTML 回测报告（浏览器打开就能看）
- 一套**和 AI 协作做量化研究的 Prompt 模板**（这才是你关注的 AI coding）
- **真实 A 股数据接口**（akshare 新浪源，带本地缓存，第二次跑秒出）

## 怎么跑（30 秒）

```powershell
# 1. 装依赖
python -m pip install -r requirements.txt
# 想接真实数据，再装：
python -m pip install akshare

# 2. 一键跑（演示数据，0 外网依赖）
python run.py

# 3. 跑真实沪深300（2023年至今）
python run.py akshare 000300 2023-01-01

# 4. 换别的指数
python run.py akshare 399006 2023-01-01   # 创业板指
python run.py akshare 000905 2023-01-01   # 中证500

# 5. 用浏览器打开
results/report.html
```

## 真实数据回测结果（沪深300，2023-01-03 ~ 2026-10-23）

这是用**真实 A 股指数**跑出来的数字，不是模拟数据：

| 策略 | 累计收益 | 年化 | 夏普 | 最大回撤 | 胜率 | 交易数 |
|---|---|---|---|---|---|---|
| 买入持有（基准） | +5.59% | — | — | — | — | — |
| **RSI 均值回归** | **+11.81%** | +3.11% | **0.11** | -21.43% | **66.7%** | 3 |
| 唐奇安突破 | +7.02% | +1.88% | -0.01 | -15.26% | 30.8% | 13 |
| AI 投票组合 | +2.65% | +0.72% | -0.13 | **-12.02%** | 38.5% | 13 |
| 双均线趋势 | -6.41% | -1.80% | -0.33 | -20.25% | 11.1% | 9 |

**这张表才是这个项目真正想教你的东西：**

1. **RSI 均值回归在真实沪深300上跑赢了基准一倍。** 不是演示数据上的巧合——
   2023-2024 年 A 股反复震荡探底，恐慌买入的策略确实吃到了肉。
2. **双均线在真实数据上还是亏。** 趋势策略在震荡市里被反复打脸，
   胜率只有 11%——但盈亏比 5.58，说明它靠极少数大赚撑着。这就是趋势跟踪的本质：
   平时小亏，一年等一两次大行情。
3. **组合策略回撤最小（-12%）但收益也最低。** 分散化的代价就是收益被摊薄，
   但它睡得着觉。你以后做实盘，回撤控制比收益重要。
4. **所有策略夏普都不到 1。** 这就是现实——单一个股指数上的简单技术策略，
   年化能跑赢基准 3-5 个点已经算不错。真正的 alpha 来自多因子、多标的、另类数据。

## 为什么是你（一个软工学生），为什么是现在

你 20 岁，大二，软件工程，在实习量化，关注 AI coding。
我不打算给你灌鸡汤，说几句实话：

**1. 量化这行现在的真实窗口。**
过去 10 年是"数学/物理 PhD + 传统统计模型"的天下。
但从 2022 年 LLM 爆发之后，行业正在经历一次**范式重写**：
- 因子挖掘从"人拍脑袋想公式"变成"人 + LLM 头脑风暴 + 机器验证"；
- 另类数据（新闻、研报、社媒）从"看一眼"变成"NLP 批量处理"；
- 回测、debug、写研究报告这些原本占 80% 时间的工程活，
  AI 能接走 50% 以上。

**这意味着什么？** 纯金融背景的人在工程上追不上你；
纯工程背景的人在金融直觉上需要补。**你站在中间这个交叉点上。**
现在入场不晚——这个交叉点才刚刚打开 2-3 年。

**2. 你最大的优势不是"会写代码"，是"知道工程的边界在哪"。**
很多学金融的人也会写 Python，但他们不知道：
什么是未来函数、什么是幸存者偏差、什么是过拟合、
为什么随机种子重要、为什么回测对了不等于实盘对。
这些"工程直觉"是你作为软工学生的肌肉记忆。
这个项目里每一行注释都在反复强化这些直觉。

**3. AI coding 不是"让 AI 帮你写代码"。**
打开 `quant_seed/ai_researcher/prompts.py`，里面有 5 个 Prompt 模板：
头脑风暴、因子设计、代码 review、坏回测诊断、6 个月路线图。
真正的工作流是：

```
你提出一个模糊直觉（"恐慌之后会反弹？"）
    ↓
用 StrategyHypothesis 表把它写成可证伪的假设
    ↓
让 AI 帮你把假设翻译成策略代码
    ↓
你自己 review 代码（用 PROMPT_CODE_REVIEW 模板）
    ↓
回测，结果不好就用 PROMPT_DIAGNOSE_BAD_BACKTEST 让 AI 帮你诊断
    ↓
你拍板：这个想法是真的 edge 还是样本内噪音？
```

**你是那个拍板的人，AI 是你的分析师。**
这个角色分工，是这个时代最值钱的能力之一。

## 接下来你可以做什么（按难度排序）

**Level 1（今天就能做）**
- 改 `MACross(fast=5, slow=20)`，看真实数据上结果怎么变
- 把 `config.py` 里的手续费从万三改到万十，看策略还活不活
- 在 `strategies/` 里抄一个新文件，写一个你自己的策略

**Level 2（这周做）**
- 跑一下 `python run.py akshare 399006 2023-01-01`（创业板指），
  对比沪深300和创业板指上策略表现的差异
- 想想：为什么 RSI 在创业板上可能不灵？波动更大？趋势更强？
- 做一次**参数敏感性分析**：RSI 的 low/high 在 25-35 / 65-75 之间扫一遍

**Level 3（这个月做）**
- 用 `prompts.py` 里的模板，让 AI 帮你设计一个新因子（比如"波动率突变"）
- 实现它，加进组合策略，看能不能改善夏普
- 做一次**样本外测试**：用 2023-2024 年数据调参数，2025-2026 年数据验证

**Level 4（这个学期做）**
- 加一个**风险模块**：波动率仓位调整（波动大就少买）
- 加一个**多标的回测**：不只看一个指数，看一篮子股票
- 写一个 Jupyter notebook，把整个研究过程记录下来
  ——这就是你以后简历上的第一个项目
